# Optional Sketchfab monsters (CC BY 4.0)

Download each model's **GLB** from Sketchfab (needs a free account) and save it here with
these exact names. The game picks them up automatically; if a file is missing, the Kenney
model is used instead. Orientation/size tweaks live in `CUSTOM_MODELS` in `src/assets.js`.
